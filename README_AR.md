# خِدمتك – سوريا

مشروع تجريبي لتطبيق خدمات محلية في سوريا، يعمل باستخدام Node.js وExpress وواجهة عربية.

## التشغيل محليًا
1. ثبّت Node.js.
2. نفّذ `npm install`.
3. نفّذ `npm start`.
4. افتح `http://localhost:3000`.

## النشر التجريبي على Render
- ارفع ملفات هذا المشروع إلى مستودع GitHub.
- في Render اختر New > Web Service واربط المستودع.
- Build Command: `npm install`
- Start Command: `npm start`
- فحص الصحة: `/api/health`

## تنبيه مهم
هذه نسخة أولية للاختبار وليست جاهزة بعد للاستخدام العام واسع النطاق. قاعدة البيانات الحالية ملف JSON، وقد لا تبقى البيانات بعد إعادة تشغيل الخدمة أو إعادة نشرها على الاستضافة المجانية. قبل استقبال بيانات حقيقية، استخدم قاعدة بيانات دائمة مثل PostgreSQL، وأضف حماية تسجيل الدخول، ومراجعة البلاغات، وسياسة خصوصية، ونسخًا احتياطية. بيانات مقدمي الخدمات الطبية ليست موثقة تلقائيًا.
